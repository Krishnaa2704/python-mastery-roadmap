# Module 01 — Python Fundamentals

## Outcomes

By the end of this module, you should be able to:

- Explain how a Python script is executed.
- Use variables and follow naming conventions.
- Identify common built-in data types.
- Convert between compatible types.
- Use arithmetic, comparison, logical, and assignment operators.
- Read input and display formatted output.

## Study order

1. Python interpreter, scripts, and the development environment.
2. Variables and naming conventions.
3. Integers, floats, strings, booleans, and `None`.
4. Type checking with `type()` and type conversion.
5. Arithmetic, comparison, logical, and assignment operators.
6. `input()`, `print()`, and f-strings.

## Practice rules

- Type each example yourself; do not copy-paste a complete solution.
- Predict the output before running the code.
- Change the input values and test edge cases.
- Add a short comment explaining anything that initially confused you.

## Exercises

1. Store a person's name, age, and city in variables and print a formatted introduction.
2. Convert a temperature from Celsius to Fahrenheit.
3. Given two numbers, display their sum, difference, product, quotient, and remainder.
4. Calculate the total price after applying a percentage discount.
5. Read a number from the user and display its type before and after conversion.

Do not move on just because the examples run. Make sure you can solve these variations independently.
